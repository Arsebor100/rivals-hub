# Rivals Hub

A small catalog and status tracker for Roblox Rivals-related community projects.

## Run locally

Open `index.html` directly in a browser, or use a lightweight local web server:

```bash
cd /path/to/rivals-hub
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## What it includes

- searchable catalog
- status filters
- project cards with pros/cons
- quick project submission form
- dark gaming-style UI

## Notes

This is a simple front-end MVP. You can later replace the in-memory data with a real backend/database if you want a more advanced version.
